# Platform Adaptation

## Default: WeChat Channels

Prioritize:
- comprehensible depth over hyper-fast meme pacing
- strong first 3–5 seconds
- clear social/news context
- quotable core judgment
- natural sharing value
- enough explanation to make the viewer feel informed, not merely entertained

Default: 2–4 minutes unless topic complexity clearly suggests otherwise.

## Douyin

Adjust by:
- moving the strongest fact/result even earlier
- reducing setup before the first payoff
- shortening background blocks
- increasing frequency of new beats in the first 30 seconds
- using more visually explicit numbers/maps/cards

Do not sacrifice factual qualifications or manufacture suspense.

## Bilibili

Allow:
- longer setup after the initial hook
- more historical context
- more mechanism detail
- more comparison/counterexample
- slower diagrams/maps/data explanations

A 4–7 minute version is acceptable when the source article genuinely supports it.

## Duration selection

### 60–120 seconds
Use when one contradiction + one mechanism is enough.

### 2–4 minutes
Default for a complete news explanation.

### 4–7 minutes
Use when the subject needs history, multiple actors, technical background, or geopolitical context.

Never choose duration only because a platform is called “short video”.

## Platform commands

- `短一点` → prioritize 60–120 sec.
- `正常视频` → 2–4 min.
- `深度视频` → 4–7 min.
- `视频号版` → balanced default.
- `抖音版` → faster, tighter.
- `B站版` → deeper and more contextual.
