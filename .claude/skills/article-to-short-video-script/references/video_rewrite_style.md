# Video Rewrite Style Guide

## Re-engineer, do not summarize

Treat the source article as a research library, not as a fixed sequence.

Preserve:
- core verified facts
- strongest explanatory mechanism
- the best historical/contextual expansion
- the conclusion that changes how the viewer understands the event

Cut or compress:
- repeated setup
- article-only transitions
- secondary examples that do not alter understanding
- multiple similar statistics
- explanatory detours with weak visual value

## Opening patterns

Use only when factually supported:

### Result first
State the unexpected outcome, then withhold the mechanism.

### Behavior contradiction
Describe an action that looks irrational until the rule is explained.

### Scale number
Use one number that instantly establishes magnitude.

### Historical mismatch
Connect the scene to an older pattern, then explain similarities and differences.

### Mechanism question
Ask one specific question that the rest of the video can genuinely answer.

Avoid generic suspense such as “看到最后你会震惊”.

## 15-second architecture

A useful opening usually follows:

**A happened → normally B should follow → instead C happened → the reason is hidden in D.**

D can be a rule, geography, technical limitation, incentive, historical residue, or institutional design.

## Information beats

A beat is not necessarily a sentence. It is one new unit of audience value.

Useful beats:
- concrete detail
- causally relevant event
- person/actor entry
- one strong number
- rule reveal
- historical context
- reversal
- visual explanation
- reframing conclusion

Aim for a new beat every 15–30 seconds; faster for Douyin openings.

## Spoken Chinese

Write for the mouth:

- one main idea per breath group
- reduce written connectors like “鉴于/与此同时/因此可以看出”
- put qualifications near the claim they qualify
- split complex sentences before they become hard to voice
- read exact numbers only when precision itself matters
- use screen text for dates, legal names, percentages, or citations

## Rhythm

A reliable rhythm is:

**long informational push → short punch → question/turn → explanation → short redefinition.**

Do not make every line short. Continuous staccato becomes tiring and fake.

## Humor and internet language

Use humor as an explanatory compression layer, not decoration.

Strong humor types:
- defamiliarization
- personification
- formal-register mismatch
- extended metaphor
- concrete analogy
- role reversal

Weak humor:
- random memes
- repeated catchphrases
- irrelevant insults
- forced puns that do not explain anything

## Cognitive ending

The final 10–20 seconds should preferably do one of:

- redefine what the story was really about
- return to the opening anomaly with a deeper explanation
- show why the mechanism may recur
- create a historically grounded callback

Avoid generic moralizing or “大家怎么看”.
