# geopolitical-deep-analysis-wechat

A reusable Agent Skill for current, source-grounded geopolitical research and Chinese WeChat long-form publishing with a mandatory `.docx` delivery workflow.

## Typical invocation

- `分析现在的俄乌冲突，并输出微信公众号 Word。`
- `选题：为什么美国越来越重视菲律宾？`
- `用 geopolitical-deep-analysis-wechat 分析中美半导体竞争。`

## Package

- `SKILL.md` — activation metadata and core workflow
- `references/` — sourcing, methodology, editorial, DOCX, safety standards
- `templates/analysis-outline.md` — reusable article scaffold

This package follows the Agent Skills folder convention: a skill directory with a required `SKILL.md` and optional supporting resources.
